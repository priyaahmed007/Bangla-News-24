# 📰 Bangla News 24

Bangla News 24 is a modern news portal where users can explore the latest news across different categories, including politics, world affairs, economy, health, sports, and technology. Users can browse news headlines and summaries, while reading full news details requires authentication.

## ✨ Features

- 📰 **Latest News:** Browse the latest news, featured stories, and updates.
- 📂 **News Categories:** Explore news from different categories.
- 🔥 **Most Popular News:** Discover popular news articles.
- 🔐 **Protected News Details:** Sign in or sign up to read full news articles.
- 🔑 **Multiple Authentication Options:** Register or sign in using email and password, Google, or GitHub.
- 👤 **Profile Management:** Update profile information after signing up.
- 📱 **Responsive Design:** Enjoy a smooth experience on desktop, tablet, and mobile devices.
- 🧭 **Easy Navigation:** Browse news through a clean and user-friendly interface.

## 🔑 Authentication

Bangla News 24 provides authentication-based access to detailed news content.

- Create an account using email and password.
- Sign in to an existing account.
- Authenticate using Google or GitHub.
- Access full news details after signing in.
- Update profile information after registration.

## 🛠️ Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- REST API
- Google and GitHub Authentication

## 🎯 Project Goal

The goal of Bangla News 24 is to provide a convenient and user-friendly platform for browsing news, exploring popular stories, and accessing detailed articles through an authenticated user experience.
